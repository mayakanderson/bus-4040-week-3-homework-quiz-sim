# bus-4040-week-3-homework-quiz-sim

Homework 3 (BUS 4040, AI for Business Applications), Part 2: "vibe code" a quiz simulator, one-shot.

## What's in this repo

- index.html, the quiz simulator. A single self-contained file: no server, no build step, no internet connection, no external libraries. Double-click it to open it in your browser and take the quiz.
- material/, the Week 1-3 narratives and homework files the quiz questions were drawn from. Nothing in the quiz comes from outside these files.

## The prompt I used

I'm a business student in an introductory AI course (BUS 4040, AI for Business Applications). Build me a quiz simulator so I can test my understanding of the course material so far.

Source material: use ONLY the files in the material/ folder of this repo, the weekly narratives and homework documents for weeks 1 through 3. Do not add facts from outside these files. If something in the material is unclear, skip it rather than guessing.

What to build: one self-contained index.html file that runs when I double click it. No server, no build step, no internet connection, no external libraries. Put the HTML, CSS, JavaScript, and all the questions in that single file.

How the quiz should work:
- 20 questions drawn from the material, a mix of multiple choice and true/false
- One question at a time, shuffled on each run
- Tell me immediately whether I was right, and explain why
- Name which week each answer comes from so I know where to review
- Show my score at the end, and let me retry just the ones I missed

Use plain language. Don't introduce terms the course material doesn't use.
